# XXII — полный комплект

1. Открыть index.html в браузере — работающий интерфейс без сборки, CDN и сервера. Поиск, фильтры, вкладки и детальный просмотр работают.
2. Открыть gallery.html — все 22 пары изображений.
3. Использовать DESIGN-SPEC.md и theme.css как фиксированные правила реализации.
4. Подключать арканы по cards.json. Поля day и list указывают на разные файлы.

## Содержание
- assets/cards/day: 22 подробные иллюстрации PNG с прозрачностью.
- assets/cards/list: 22 отдельно сгенерированные миниатюры PNG с рамкой.
- assets/decor: декор шапки, звёзды, рамка, пергамент, текстура.
- assets/ui: векторные UI-иконки.
- fonts: 6 локальных файлов шрифтов с кириллицей и лицензии.
- theme.css, index.html, preview.js: исходники рабочей сборки.
- cards.json / cards.js: реестр арканов и ассетов.
- gallery.html: визуальная проверка всего комплекта.
- AGENT-INSTRUCTIONS.md: инструкция агенту по интеграции и проверке полноты.
- DESIGN-SPEC.md: правила, геометрия и таблица всех файлов.
- PROMPTS.md: промпты двух изображений каждого аркана.
- QA.md / previews: выполненные проверки и снимки реализации.

Растровые изображения заново сгенерированы по стилю левого экрана. Это авторская интерпретация традиционной символики старших арканов; не репродукция конкретной колоды. Реализация воспроизводит структуру и стиль референса, а не исходный недоступный макет.

Для production можно оптимизировать PNG в lossless WebP/AVIF с сохранением alpha средствами вашего pipeline. Исходные PNG остаются эталонными. Шрифты и декор уже поставлены локально. Учебные тексты и сохранение прогресса — вне демонстрационного интерфейса.
