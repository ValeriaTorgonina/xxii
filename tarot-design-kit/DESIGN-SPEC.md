# XXII — Antique Gold: спецификация реализации

Эталон — левый золотой экран предоставленного референса. Значения ниже являются фиксированными решениями для реализации. Скрин не содержит исходных токенов, поэтому это воспроизводимая интерпретация, а не обещание пиксельного совпадения. Рабочая сборка — index.html; все визуальные зависимости поставляются в пакете.

## 1. Состав
44 отдельно сгенерированных RGBA PNG: 22 сцены карты дня и 22 миниатюры с гравированной рамкой. Миниатюра генерировалась с соответствующей большой иллюстрацией как референсом. Это две композиции для каждой карты, а не один файл, назначенный на две роли. Они могут иметь небольшие различия деталей; не использовать их как документальную копию определённой колоды.

Декор: header-ornament.png; stars.svg; panel-frame.svg; parchment-pill.svg; paper-noise.svg. UI: search.svg, chevron-right.svg, arrow-right.svg, sparkle.svg, moon.svg. Содержание: cards.json + идентичный cards.js для открытия демо без сервера. Локальные шрифты Cormorant Garamond и Inter 400/500/600, кириллица, лицензии OFL. Никаких внешних CDN-запросов.

| --gold | #B99762 | Номера, значимые иконки, фокус границы при необходимости |
| --line | #66543A | Декоративные обводки |
| --paper | #E8D6B6 | Активная вкладка/фильтр, focus |
| --ink | #211B12 | Текст на пергаменте |
| --danger | #E59C92 | Ошибка с текстом и значком |

Один золотой тон для живого UI. PNG содержат естественные вариации гравюры, не перекрашивать CSS filter. Никакого неона или свечения панелей. Текстура только на фоне; opacity слоя .35 × внутренняя opacity SVG .08 ≈ 2.8%. Тонкая рамка декоративная; для состояния, которое определяется только рамкой, использовать --gold. Не использовать --line как цвет текста.

## 4. Геометрия
База отступов 4 px. Контент максимум 440 px по центру. На 390 px поля 20 px, ширина контента 350 px; на ≤360 px поля 16 px. Верх 16 px + safe-area, низ 24 px + safe-area. Нет нарисованного корпуса телефона, статус-бара или нижнего системного индикатора.

| Компонент | Геометрия |
|---|---|
| Шапка | min-height 110 px; растёт при переносах; заголовок и подзаголовок по центру |
| Декор шапки | абсолютный слой, 110 px высота, ширина content+24; contain; opacity .72 |
| Вкладки | 46 px; 3 px внутренний отступ; 2 равные колонки; gap 4 |
| Карта дня | min-height 142 px; padding 16×18; радиус 16; рамка 1 |
| Иллюстрация карты дня | 142×153 px; справа/снизу -5; contain; opacity .82 |
| Поиск | 46 px; горизонтальный padding 15; gap 12; радиус pill |
| Фильтры | min-height 44 px; gap 8; горизонтальный scroll; без переноса |
| Строка карты | min-height 76 px; радиус 14; padding 3px 12px 3px 2px |
| Сетка строки | 66 / 28 / minmax(0,1fr) / 18 px; gap 12 |
| Миниатюра | 66×68 px; contain; рамка уже в PNG |
| Между строками | 7 px |
| Расстояния секций | 16 px; перед списком 14 px |

На ≤360 px: миниатюра 52×64, номер 24, стрелка 16, gap 8, название 20. Названия и вопросы могут переноситься; высота строк не фиксирована. Номер 0 для Шута; дальше I–XXI. В этом наборе порядок Rider–Waite: VIII Сила, XI Справедливость. Не менять индексы без изменения карточных данных.

## 5. Слои
Порядок слоя карты дня: фон поверхности → PNG справа → затемнение слева → живой текст → декоративная рамка. Затемнение: linear-gradient(90deg, surface 0%, surface 38%, rgba(21,22,17,.8) 59%, transparent 82%). Текст max-width 76%, на малом экране 80%. Вопрос max-width 235 px. Полная сцена может быть видна через детальную карточку; в баннере используется небольшая иллюстрация справа. Не растягивать PNG и не вырезать персонажа из сцены.

panel-frame.svg применяется border-image с slice 24, border 14 px в абсолютном псевдоэлементе. Это отдельная декоративная рамка поверх обычной стабильной геометрии. parchment-pill.svg — background выбранной вкладки и выбранного фильтра; живой текст поверх, цвет --ink. stars.svg размещается один раз за всем контентом и не двигается при hover. Декор pointer-events:none и aria-hidden.

## 6. Подключение
Берите картинки по `cards[id].day` и `cards[id].list`, не вычисляйте по названию. Используйте стабильные id 00…21. В production пути должны разрешаться вашим bundler/asset pipeline относительно публичной папки; если public содержит assets, используйте `/assets/cards/day/09.png` и аналогичные абсолютные пути. В демо пути относительны index.html.

Миниатюры img alt="": название карты рядом уже даёт доступное имя. Значимые изображения в детальном просмотре: alt = название аркана. Декор: alt="". Image placeholder занимает ту же геометрию. Для первого viewport 5 миниатюр eager, остальные lazy. Не загружать все большие сцены на стартовом экране: только текущую карту дня и упражнение; gallery — отдельная проверочная страница.

## 7. Состояния и поведение
Вкладки: role=tablist/tab, aria-selected, roving tabindex, ArrowLeft/ArrowRight/Home/End; связанный tabpanel. Выбранная вкладка — пергамент, текст --ink. Все элементы минимум 44 px по высоте. Фильтры кнопки aria-pressed: ровно один активный; группы 0–VII / VIII–XIV / XV–XXI. Поиск проверяет название, короткое значение и номер без учёта регистра; не меняет выбранную группу. Нет результатов — текст и «Сбросить поиск».

Строка и карта дня — один интерактивный элемент на всю площадь. В демо открывают dialog с большой сценой; в приложении допускается переход на экран аркана. Не вкладывать кнопку в ссылку. Кнопки отвечают на hover цветом поверхности, pressed сдвигом 1 px; transition 120 ms ease-out только при разрешённых анимациях. Reduced-motion отключает эти эффекты. Disabled: disabled + opacity .45. Focus-visible 2 px --paper, offset 3 px.

Практика в демо — рабочий просмотр изображения с раскрытием названия и переходом к следующему. Это проверка переиспользования ассетов; полноценная учебная механика, оценки, прогресс, сохранение и алгоритм карты дня — задачи приложения. Вопросы и короткие значения в cards.json — редакционные демонстрационные тексты, которые можно заменить.

Ошибка загрузки картинки должна оставлять размер ячейки, показывать текстовый fallback и кнопку повтора на соответствующем экране. Loading — skeleton тех же размеров; aria-busy для обновляющегося контейнера. Не генерировать номер или название внутрь изображения.

## 9. Проверка перед интеграцией
Открыть index.html и gallery.html. Все 44 файла должны существовать, иметь alpha и разрешаться без 404. Проверить 320, 390, 430, 768 px; longest titles «Колесо Фортуны», «Справедливость»; пустой поиск; переключение групп и вкладок; dialog клавишей Escape; 200% zoom; reduced-motion; safe-area. Основной экран не имеет горизонтального скролла, кроме намеренного скролла фильтров. Контраст текста ≥4.5:1; важные графические сигналы ≥3:1.

Техническая проверка и изображения реализованного экрана находятся в QA.md и previews/. Все ассеты поставлены отдельно, ничего не надо извлекать из скриншотов. Промпты генерации — PROMPTS.md.
